# Happy Birthday,

A handmade, fully static digital birthday card.

## What's inside

- `index.html` — the whole page
- `style.css` — all the styling, animations, and glassmorphism
- `script.js` — all the interactions (confetti, quiz, music, cake, sakura petals, balloons)
- `img/` — put your photos here (`hero.jpg` is used at the top, `screenshot.png` in the chat section)
- `music.mp3` — add this file next to `index.html` to play your own song

## How to use

1. Replace `img/hero.jpg` with your own hero image (or keep the current one).
2. Drop a chat screenshot at `img/screenshot.png` if you want it to appear in the "Little Chats, Little Memory" section.
3. Add a `music.mp3` file in this folder if you want background music.
4. Open `index.html` in any browser — no server needed.

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload these files to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main`, and folder `/ (root)`.
5. Save. Your site will be live at `https://yourusername.github.io/your-repo-name/`.

That's it — no build step, no backend, no APIs.
